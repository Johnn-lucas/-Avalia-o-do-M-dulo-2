# Sistema de Registro de Atividades de Cuidadores

## 📋 Descrição do Projeto

Este projeto visa criar uma aplicação web para facilitar o registro e gerenciamento das atividades realizadas por cuidadores de pessoas, como idosos ou pacientes em domicílio. Atualmente, esses registros são feitos manualmente, o que gera risco de perdas, falhas e falta de acesso remoto às informações.

A plataforma permite que cuidadores cadastrem atividades diárias, que podem ser visualizadas em tempo real por familiares e profissionais da saúde. O sistema foca em segurança, usabilidade e responsividade.

---

## 🎯 Objetivo

Desenvolver uma aplicação web que substitua os métodos manuais de registro, permitindo que cuidadores registrem suas rotinas de forma prática e segura, com acesso online por todos os envolvidos.

---

## ⚙️ Tecnologias Utilizadas

- HTML5 / CSS3
- JavaScript
- Framework Web (Ex: React ou Vue.js)
- Node.js (backend)
- MongoDB ou Firebase (armazenamento de dados)
- Git e GitHub para versionamento

---

## 🚀 Como Executar

1. Clone este repositório
2. Instale as dependências (caso esteja usando framework)
3. Execute `npm start` para iniciar o servidor local
4. Acesse via navegador: `http://localhost:3000`

---

## 📌 Funcionalidades

- Cadastro de atividades por cuidadores
- Listagem de registros por data e nome
- Acesso remoto por responsáveis
- Interface responsiva e acessível
